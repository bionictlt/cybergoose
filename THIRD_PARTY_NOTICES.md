# Third-party components

Cybergoose uses the macOS system frameworks and system libcurl.
Release app bundles additionally include:

- **libssh2** — BSD-style license: [license text](docs/licenses/libssh2.txt).
- **OpenSSL 3** — Apache License 2.0: [license text](docs/licenses/OpenSSL.txt).

The app build script copies these licenses into `Cybergoose.app/Contents/Resources/Licenses`.
